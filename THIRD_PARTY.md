# Third-party standards and dependencies

- Open Knowledge Format v0.2 specification: GoogleCloudPlatform/knowledge-catalog, Apache-2.0.
- SQLite FTS5: SQLite project documentation and the SQLite license.
- PyYAML and filelock retain their respective licenses.
- PyInstaller is used only to build the standalone release applications and retains its GPL-2.0-or-later license with its exception for bundled applications.

No third-party source code is vendored in this repository.
