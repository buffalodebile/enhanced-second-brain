# Operations

```bash
esb --vault /path/to/vault doctor
esb --vault /path/to/vault index query "question"
esb --vault /path/to/vault page read concepts/page.md
esb --vault /path/to/vault usage record cited concepts/page.md
esb --vault /path/to/vault graph path page-a page-b
esb --vault /path/to/vault reconcile
```

MCP runs over local stdio. Read tools are enabled by default; writes require `mcp.allow_writes=true`.

The Enhanced governance fields are extensions and must not be represented as official OKF requirements. FTS5 is a low-overhead lexical default, not a universal replacement for semantic retrieval. Obsidian is optional. Pure web chats cannot access a local vault without an explicit bridge.

Archival eligibility requires all configured coldness conditions and no protection. `prune apply` moves pages under `_archives/pruned/<date>/`; `prune restore` reverses the move. Scheduled backups require a private Git remote plus explicit `[backup] enabled = true`, and use a temporary index so they do not alter the live worktree, real index, or `HEAD`.
